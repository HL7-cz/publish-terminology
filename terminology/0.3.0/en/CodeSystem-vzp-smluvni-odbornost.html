CodeSystem: VZP - smluvní odbornost pracovišť

Official URL: https://ncez.mzcr.cz/terminology/CodeSystem/vzp-smluvni-odbornost Version: 770
Active as of 2026-07-27 Computable Name: VzpSmluvniOdbornost

This Code system is referenced in the definition of the following value sets:

Language: cs
